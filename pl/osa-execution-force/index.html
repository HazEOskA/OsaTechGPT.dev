System · Authority & Capability Control

OSA Execution Force: authority przed mutacją

Execution Force kontroluje ścieżkę od taska do realnej akcji. Policy, repozytorium, scope, provenance i dokładny downstream payload są związane przed wykonaniem mutacji.

TWIERDZENIE ≠ DOWÓD. Brak dowodu = UNKNOWN.
Authority path

Policy znajduje się przed execution

GODMODE V3 wybiera policy/card, wiąże repo, scope, source SHA i payload, a dopiero potem autoryzuje downstream RuntimeV2.

TASK → GODMODE V3 → CARD / POLICY → bound repo + scope + source SHA + payload → RuntimeV2 → HOST ACTION → EVIDENCE
Fail closed

Runtime state sam nie otwiera mutation authority

  • Direct RuntimeV2 przed V3 authorization jest denied.
  • RuntimeV2 state nie autoryzuje mutacji repo.
  • Payload jest związany z konkretną autoryzacją.
  • Scope repo/file nie może zostać rozszerzony downstream.
  • Brak lub UNKNOWN source SHA fail-closed.
